# Query Path Guardrails

Current-runtime `logs` is an external, read-only, mixed emission-event projection; it remains the legacy source for the current note/event read model but is not the target fiscal authority. Smart Notas owns all fiscal notes and documents only in the target path after capability promotion, when `logs` is restricted to integration-failure evidence. Queries must not assume `ref_id` uniqueness and must preserve SQL/TypeScript classification equivalence. External writer/ingestion/filter behavior is unknown. Treatments are application-owned append-only records.
